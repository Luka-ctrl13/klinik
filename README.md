# 📘 BilimJournal — Электронный журнал преподавателя

Дипломный проект: **«Разработка программного обеспечения электронного журнала преподавателя»**.
Веб-приложение в стилистике электронного журнала **BilimClass** с возможностью **выгрузки и загрузки данных журнала в таблице** (Excel / CSV).

Работает на **реальных данных**: контингент студентов колледжа (2332 студента) и учебные группы с дисциплинами (103 группы), импортированные из исходных файлов.

---

## ✨ Возможности

| Модуль | Описание |
|--------|----------|
| 🏠 **Главная** | Сводная статистика, графики средних баллов и распределения оценок |
| 📊 **Журнал оценок** | Таблица «студенты × даты уроков»: ввод оценок (2–5) и отсутствий («Н»), автоматический подсчёт среднего балла, навигация стрелками |
| 📚 **Темы уроков (КТП)** | Календарно-тематическое планирование по датам |
| ✅ **Посещаемость** | Отметка присутствия/отсутствия студентов на дату |
| 👥 **Контингент** | Список всех студентов с поиском и постраничным выводом |
| 🏫 **Группы** | Карточки учебных групп с дисциплинами и показателями |
| 📈 **Аналитика** | Качество знаний, успеваемость, посещаемость, рейтинг студентов, графики |
| 💾 **Импорт / Экспорт** | **Выгрузка журнала в Excel/CSV и загрузка обратно**, экспорт контингента, резервные копии (JSON) |
| ⚙️ **Настройки** | Профиль преподавателя, система оценивания, очистка данных |

## 💾 Выгрузка и загрузка журнала (ключевая функция)

- **Выгрузка** — кнопки «⬇ Excel» / «⬇ CSV» в журнале или на странице «Импорт / Экспорт». Таблица содержит: №, ФИО, оценки по датам, средний балл и темы уроков.
- **Загрузка** — перетащите файл `.xlsx` / `.csv` в зону загрузки. Оценки сопоставляются со студентами **по ФИО** и добавляются в выбранную группу/дисциплину. Новые даты и темы создаются автоматически.

## 🚀 Запуск

Не требует сборки. Достаточно открыть `index.html` или поднять статический сервер:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

**Демо-вход:** логин `teacher`, пароль `1234`.

## 🛠 Технологии

- **HTML / CSS / Vanilla JavaScript** (SPA с hash-роутингом, без фреймворков)
- **localStorage** — хранение оценок, тем и настроек
- **SheetJS (xlsx)** — чтение/запись Excel (подключён локально в `assets/js/vendor/`, работает офлайн)
- **Chart.js** — графики аналитики (локально, офлайн)
- Шрифт Inter

> Библиотеки лежат прямо в проекте, поэтому импорт/экспорт Excel работает без интернета.
> CDN используется только как запасной вариант, если локальные файлы отсутствуют.

## 📁 Структура

```
index.html              # вход + оболочка SPA
assets/css/style.css    # стили (тема BilimClass)
assets/js/data.js       # реальные данные (студенты, группы, дисциплины)
assets/js/storage.js    # слой данных (localStorage)
assets/js/io.js         # импорт/экспорт Excel и CSV
assets/js/app.js        # роутер и экраны
```

> Все данные журнала хранятся локально в браузере. Для переноса используйте «Резервная копия (JSON)» в разделе «Импорт / Экспорт».
